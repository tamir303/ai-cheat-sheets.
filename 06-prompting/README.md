## LinkedIn post

```text
Same question, six ways to prompt it, six different accuracy (and cost) profiles.

Before you fine-tune or reach for a bigger model, change how you ask.

The short version:
→ Simple, well-defined tasks: zero-shot
→ Strict format or labels: few-shot examples
→ Math and multi-step logic: chain-of-thought
→ You need a more reliable final answer: self-consistency (sample and vote)
→ Hard problems with clear sub-steps: least-to-most
→ Puzzles and plans with dead ends: tree of thoughts

Rule of thumb: start zero-shot, add examples for format, and only pay for multiple calls where accuracy is worth it.

Which technique gives you the biggest lift?
```
