## LinkedIn post

```text
Eight milestones from LSTMs to GPT-3, and the limit each one fixed.

Every model in this story removed one bottleneck of the model before it.

→ 1997 LSTM: plain RNNs forgot after a few steps
→ 2013 word2vec: words became vectors with meaning
→ 2014 Seq2seq: translation became one trainable network
→ 2014 Attention: no more squeezing a sentence into one vector
→ 2017 Transformer: no recurrence, so training runs in parallel
→ 2018 GPT and BERT: pre-train once, adapt to many tasks
→ 2020 GPT-3: examples in the prompt began to replace fine-tuning

Rule of thumb: to understand a new architecture, ask which bottleneck of the last one it removes.
```
